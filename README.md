# 🎗️ Breast Cancer Prediction using Machine Learning

## Overview

This project predicts whether a breast tumor is Benign or Malignant using Machine Learning techniques. The model is trained on breast cancer diagnostic data and deployed as an interactive Streamlit web application.

## Features

- Data preprocessing and feature scaling
- Machine Learning model training and evaluation
- Hyperparameter tuning using GridSearchCV
- Interactive Streamlit web application
- Real-time prediction from user inputs
- Easy deployment and usage

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- XGBoost
- Streamlit
- Joblib
- Matplotlib

## Dataset

The dataset contains diagnostic measurements extracted from digitized images of breast mass cell nuclei.

Features include:

- Texture Mean
- Smoothness Mean
- Compactness Mean
- Concave Points Mean
- Symmetry Mean
- Fractal Dimension Mean
- Texture SE
- Area SE
- Smoothness SE
- Compactness SE
- Concavity SE
- Concave Points SE
- Symmetry SE
- Fractal Dimension SE
- Texture Worst
- Area Worst
- Smoothness Worst
- Compactness Worst
- Concavity Worst
- Concave Points Worst
- Symmetry Worst
- Fractal Dimension Worst

Target Variable:

- 0 → Benign
- 1 → Malignant
